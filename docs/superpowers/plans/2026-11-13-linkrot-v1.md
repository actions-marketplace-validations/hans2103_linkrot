# linkrot v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A CLI `linkrot <url>` that collects every page of a site, checks every link with lychee, lists each broken link once with the pages it is on, and reports periodic runs via a GitHub issue or mail.

**Architecture:** linkrot fetches and parses pages itself (sitemap first, else crawling) and keeps a map *link → pages*. Links it did not already fetch go to lychee as one plaintext URL list (`lychee --format json urls.txt`); lychee's error/timeout maps are merged back into the link map, classified into *broken* and *doubt*, rendered, and optionally reported. Developed and tested on Node; released as standalone binaries compiled with Bun in GitHub Actions.

**Tech Stack:** Node ≥ 22 (ESM, `node:test`, `node:util.parseArgs`), `htmlparser2`, `smol-toml`, `nodemailer`; lychee ≥ 0.24 as external program; Bun `build --compile` for releases.

**Spec:** `docs/superpowers/specs/2026-11-13-linkrot-design.md` (Dutch). Read it before starting.

## Global Constraints

- Command and binary name: `linkrot`. Config file: `.linkrot.toml` (cwd, or `--config <path>`).
- Exit codes: `0` nothing broken · `1` broken links found · `2` linkrot itself failed (site unreachable, lychee missing/too old, invalid config). Doubt never affects the exit code.
- With a report channel set (`--report github|mail` or config), broken links give exit `0` and nothing on stdout, unless `--fail-on-broken`. Tool failures still exit `2` with a message on stderr.
- Built-in excludes (always on): `^https://outlook\.(live|office)\.com/calendar/`; non-HTTP schemes `mailto: tel: webcal: javascript: data:` are never checked.
- Doubt, not broken: status 403/429/999 from hosts `linkedin.com facebook.com instagram.com x.com twitter.com` (incl. subdomains), any 429, and any timeout.
- `<link rel=canonical>`, `<link rel=alternate hreflang>` and `og:url` are never reported.
- lychee defaults: `--timeout 10 --max-retries 1 --max-concurrency 16 --cache --max-cache-age 1d`, user agent `Mozilla/5.0 (compatible; linkrot/<version>; +https://github.com/hans2103/linkrot)`.
- Minimum lychee version: `0.24.0`.
- Mail transport: SMTP from `SMTP_HOST SMTP_PORT SMTP_SECURE(tls|ssl|none) SMTP_USER SMTP_PASS` (env, else the `KEY=value` file `~/.smtp-credentials`); fallback `/usr/sbin/sendmail` when no SMTP config exists.
- English for all CLI text, README and code comments. MIT. No npm publish.
- Dependencies limited to the three above (dev: none beyond Node's built-ins).

## Review Focus

1. **Start URL redirects to another host** (`http://` → `https://`, `www.` added/removed): the redirected origin must become "the site", otherwise nothing gets crawled. → test in Task 3.
2. **Endless URL spaces** (`?start=13`, calendar `?month=` links, session ids): crawling must stop at `max_pages` (default 5000) and report that it stopped. → test in Task 3.
3. **Sitemap that lists another host or scheme** (`http://site/…` on an https site, or `www.` variant): treated as the same site, not skipped. → test in Task 2.
4. **`<base href>` in the page**: relative links resolve against it. → test in Task 1.
5. **lychee missing or older than 0.24**: exit 2 with an install hint, never a silent stop like blc. → test in Task 4.

### Task 3: Crawler

**Files:**
- Create: `src/crawl.js`, `test/crawl.test.js`

**Interfaces:**
- Consumes: `extractLinks` (Task 1), `discoverSitemapPages`, `sameSite` (Task 2).
- Produces: `crawl(opts: {startUrl: string, seeds?: string[], follow: boolean, maxPages: number, maxDepth: number, concurrency: number, userAgent: string, headers?: object, onProgress?: (n: number) => void}): Promise<CrawlResult>`
  `CrawlResult = {origin: string, pages: Map<string, {status: number|string}>, refs: Map<string, Array<{page: string, kind: LinkKind}>>, truncated: boolean}`.
  `origin` is the origin after following the start URL's redirects. Pages are fetched (GET, `accept: text/html`, 20 s timeout); only `text/html` 2xx responses are parsed. `follow: true` queues same-site links of kind `a`/`iframe` that look like pages (not `/media/`, not file extensions css/js/images/fonts/pdf/zip/xml/ics/mp3/mp4). Seeds = sitemap pages (when `follow` is false these are the only pages); the start URL is always a page. A page whose status is ≥ 400 or a network error is recorded in `pages` and also added to `refs` with the referring pages.

- [ ] **Step 1: Failing tests** (using `startServer`):
  - three linked pages, `follow: true` → `pages.size === 3`, `refs` maps `/c` to `[{page: '/b', kind: 'a'}]` (full URLs).
  - link to missing internal page `/gone` → `pages.get(.../gone).status === 404`, refs list the referrer.
  - start URL `/` responds 301 to another server (second `startServer`) → `origin` equals the second server's origin and its pages are crawled (Review Focus 1).
  - page linking `/list?start=N` → `/list?start=N+1` endlessly, `maxPages: 20` → `pages.size === 20`, `truncated === true` (Review Focus 2).
  - `follow: false`, `seeds` of two pages → only those two plus the start URL fetched.
  - external links appear in `refs` but are never fetched (assert server hit counter).
- [ ] **Step 2:** `npm test` → FAIL.
- [ ] **Step 3:** Implement with a simple promise pool of `concurrency`; depth tracked per queued URL.
- [ ] **Step 4:** `npm test` → PASS. Commit `feat: crawl a site and record link references`.

### Task 4: lychee runner

**Files:**
- Create: `src/lychee.js`, `test/lychee.test.js`, `test/fixtures/lychee-output.json`

**Interfaces:**
- Produces: `findLychee(): Promise<{path: string, version: string}>` — searches `LINKROT_LYCHEE`, then `PATH`, then `~/.local/bin/lychee`; throws `LinkrotError` (exported from `src/errors.js`, `class LinkrotError extends Error {}`) with an install hint when missing or `< 0.24.0`.
- Produces: `checkLinks(urls: string[], opts: {lychee: string, cacheDir: string, userAgent: string, excludes: string[], concurrency?: number}): Promise<Map<string, CheckResult>>` where `CheckResult = {ok: boolean, code: number|null, text: string, timeout: boolean}`. Writes `urls` one per line to a temp `.txt`, runs lychee with `cwd: cacheDir` (so `.lycheecache` lives there) and the Global Constraints defaults plus `--format json --no-progress --scheme https --scheme http` and one `--exclude` per entry. lychee exit 0 or 2 = success; other codes → `LinkrotError` with stderr. Every input URL gets a result: from `error_map`/`timeout_map`, `excluded_map` is dropped from the map, everything else `ok: true`.
- Produces: `parseLycheeJson(json: object, urls: string[]): Map<string, CheckResult>` (pure, used by `checkLinks`).

### Task 6: Configuration

Invalid TOML, unknown channel, missing url, mail without `to` → `LinkrotError`.
